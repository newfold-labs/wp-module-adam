# Getting started

Prerequisites: PHP 7.3+, Composer. The module requires wp-module-context, wp-module-data, wp-module-features.

```bash
composer install
composer run lint
composer run fix
composer i18n
```

See [integration.md](integration.md) for using in a host plugin.
