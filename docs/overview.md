# Overview

**wp-module-adam** provides Adam (Ads and More) cross-sell content for Newfold brand plugins. It registers with the Newfold Module Loader and depends on wp-module-context, wp-module-data, and wp-module-features. Maintained by Newfold Labs. Distributed via Newfold Satis.
